# La main d'Or - Menu

Site statique (HTML, CSS, JavaScript). Aucune installation requise.

## Ouvrir dans VS Code
1. Ouvrez le dossier dans VS Code (Fichier > Ouvrir un dossier).
2. Installez l'extension **Live Server** (Ritwick Dey).
3. Clic droit sur `index.html` > **Open with Live Server**.

Vous pouvez aussi double-cliquer sur `index.html` pour l'ouvrir dans le navigateur.

## Ce que vous pouvez modifier
- **Plats et prix**: dans `script.js`, tableau `DISHES` (nom `n`, prix `p`). L'ordre correspond aux images `images/ico0.png` a `ico9.png`.
- **Telephone**: cherchez `12145422273` et `(214) 542-2273` dans `index.html` et `script.js`.
- **Adresse**: cherchez `Weeding Passage Way` dans `index.html` et `script.js`.
- **Couleurs et polices**: variables au debut de `style.css` (`:root`).
- **Photo**: remplacez `images/hero.jpg`.

## Commande
La commande n'est pas envoyee automatiquement. Le client l'envoie par WhatsApp (lien `wa.me` avec le message deja redige) ou la copie, puis appelle pour confirmer. Verifiez que le numero est bien sur WhatsApp.

## Mettre en ligne
Deposez le dossier sur Netlify, Vercel, GitHub Pages ou tout hebergeur de sites statiques. Sur un vrai site, le bouton Appeler lance l'appel sur telephone.
